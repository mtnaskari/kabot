# kabot documentation

kabot is a message box for your website that delivers to Telegram and Bale. It runs on a single Cloudflare Worker, so your own server never stores messages or talks to a messaging API.

New here? **[Get started](getting-started.md)**. It takes about fifteen minutes from nothing to your first message.

## Set up

- [Get started](getting-started.md): create a bot, deploy, add a site, link your chat.
- [Telegram](telegram.md): the bot, private chats and groups, buttons and commands.
- [Bale](bale.md): use Bale instead of, or alongside, Telegram.
